# iyf-s12-week-05-Nyakito

Week 05 JavaScript practice and interactive To-Do List project.

## Project Structure

- `index.html` — To-Do List mini-project and GitHub Pages entry point
- `styles.css` — To-Do List styling and responsive layout
- `app.js` — To-Do List state, rendering, events, filtering, deletion, and editing
- `dom-practice.html` — Lesson 9 DOM practice page
- `dom.js` — Lesson 9 and Lesson 10 DOM/event practice
- `daily-challenges/` — Space for daily challenge work
- `.gitignore` — Common files excluded from Git

## Features

The To-Do List supports:

- Adding tasks
- Preventing empty tasks
- Completing and uncompleting tasks
- Deleting tasks
- Filtering by all, active, or completed
- Remaining-task count
- Clearing completed tasks
- Double-click editing
- Enter to save an edit
- Escape to cancel an edit
- Responsive layout
- Event delegation for task actions

## Concepts Practiced

This project applies DOM selection, traversal, content and attribute manipulation, element creation, event listeners, event objects, event delegation, form handling, arrays, objects, functions, filtering, and rendering.

## Run

Open `index.html` in a browser.

For GitHub Pages, keep `index.html` at the repository root.
